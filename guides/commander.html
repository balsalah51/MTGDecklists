Commander

100-card singleton led by a legendary creature. The most popular way to play Magic in 2026.

One legend. Ninety-nine unique spells. A table of stories.

Commander is 100-card singleton led by a legendary creature. The format page mixes public Duel Commander leagues with Commander lists from MTGGoldfish, Moxfield, Archidekt, and Deckstats. Color identity is the same rule used at a four-player Commander night.

Browse Commander lists by legend — one SEO page per commander on this site.

Lists live on the format pages. Shop gear uses the same Amazon short links as One Piece Deck Base. Card buy buttons use the same TCGplayer partner ID.
